SISTEMA DE REGISTRO DE PRODUCTOS
================================

DESCRIPCIÓN
-----------
Sistema de registro de productos con formulario validado en JavaScript,
cargas dinámicas desde base de datos y guardado mediante AJAX + PHP.

TECNOLOGÍAS
-----------
- HTML / CSS / JavaScript nativos (sin frameworks).
- PHP nativo (sin frameworks).
- AJAX mediante fetch().
- PostgreSQL.

VERSIONES UTILIZADAS
--------------------
- PHP: 8.3
- PostgreSQL: 18.2

REQUISITOS PREVIOS
------------------
- Tener instalado PHP con la extensión pdo_pgsql habilitada.
- Tener instalado PostgreSQL 18 (o compatible) con el servicio en ejecución.

PASOS DE INSTALACIÓN
--------------------
1. Crear la base de datos (desde una terminal con psql):

   psql -U postgres -c "CREATE DATABASE registro_productos;"

2. Importar el esquema y los datos iniciales, en este orden:

   psql -U postgres -d registro_productos -f sql/01_esquema.sql
   psql -U postgres -d registro_productos -f sql/02_datos_prueba.sql

3. Configurar las credenciales de conexión a PostgreSQL:
   Por defecto, php/conexion.php está configurado para usuario 'postgres' y clave vacía (''). Si tu PostgreSQL requiere otra clave, puedes editar directamente php/conexion.php o crear opcionalmente el archivo php/config.local.php con tu configuración.

4. Levantar el servidor de desarrollo desde la raíz del proyecto:

   php -S localhost:8000

5. Abrir en el navegador:

   http://localhost:8000/index.html

ESTRUCTURA DEL PROYECTO
-----------------------
index.html             Interfaz del formulario.
css/estilos.css        Estilos.
js/                    Validaciones, cargas dinámicas y envío AJAX.
php/                   Conexión a base de datos y endpoints del servidor.
sql/                   Esquema y datos iniciales de la base de datos.

NOTAS
-----
- No se requieren archivos de configuración adicionales: el proyecto funciona
  con los valores por defecto de php/conexion.php (usuario 'postgres', clave
  vacía). Solo si el entorno requiere credenciales distintas, editar
  php/conexion.php o crear el archivo opcional php/config.local.php
  (ignorado en git, para no exponer credenciales en el repositorio).
